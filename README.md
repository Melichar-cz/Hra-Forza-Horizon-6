# Forza Horizon 6 - Osobní  web

Vítejte v mém repozitáři věnovaném mé oblíbené závodní sérii **Forza Horizon 6**! Tento projekt slouží k procvičení práce s Gitem, Markdownem a strukturováním souborů na GitHubu.

## 🏎️ O hře
Forza Horizon nabízí obrovský otevřený svět, nádhernou grafiku a stovky licencovaných aut. Těším se na nové lokace a vylepšený fyzikální model.

* Plynulý zážitek z jízdy
* Dynamické střídání počasí
* Detailní tuning vozidel
